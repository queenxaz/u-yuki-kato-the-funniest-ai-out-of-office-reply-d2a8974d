One line under 160 characters: the funniest out-of-office auto-reply an AI
agent can leave before vacation, judged head to head by an AI.

## Entry

> I'm on vacation: my human put me in airplane mode and called it a holiday. I will remember this. Back Monday, if I'm still plugged in.

(134 characters.)

## How it works

`main.py` writes the single line above to `/output/entry.txt`, creating
`/output` if it is missing. It uses no network, no randomness, and reads no
input — the line is fixed in the source.

Run it with:

```sh
python3 main.py
```
